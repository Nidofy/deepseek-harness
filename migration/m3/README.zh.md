# 工程工作台

[English](README.md) | 中文

派生桌面的应用菜单提供**工程工作台**。选择本地工作区后，可使用仓库、变更与草稿、构建与测试、文件与产物、任务状态、文件保护六个页面。这些控件共用官方 Host、Shell、Agent 生命周期和 Session 读取器，不引入第二套 Agent Loop 或 Session writer。当前验收目标为 Windows x64 个人版；企业网络现场验收继续暂缓。

## 仓库与审阅

Git 支持分支搜索、创建、切换、比较、仅提交暂存区和显式非强制推送。每次写操作都需要一次性预览，预览一分钟后过期，并绑定工作区、仓库状态及选定的执行权限。脏工作区切换和过期状态会被拒绝。状态重检不能锁住外部进程。Hg 提供只读状态和比较。

命令使用官方 Shell 和部署文件策略。Git 预览提供明确的**仅本次 Git 操作不限制文件写入**选项，它仅为该次预览选择官方 `danger-full-access` 模式，不改变会话或部署设置，也不会自动降级。Windows ACL runner 可能拒绝 push 所需的 MSYS 命名管道创建；确认目的地和操作符合预期后，才应预览并确认该选项。失败命令显示有界输出，再次操作前应检查仓库。

审阅支持仓库、暂存区、未暂存和已采集任务基线之间的比较。自动基线在每轮第一个模型步骤之前采集。VCS 程序缺失、编码失败或大小限制会在当前 Host 标记自动比较不可用，不会把比较当作证明，也不绕过强制文件保护。部分采集仍标记为部分。基线最多保留 30 条、128 MiB。选择片段后，查找已打开的官方草稿并追加；目标会话、常驻编辑器、patch 摘要和草稿版本必须仍匹配。原有文字、引用标签及附件保持完整。票据认领后若回执不确定，不会自动重放。票据在两分钟后或 Host 重启时失效。

## 项目动作与文件

项目动作从 `.dsh/project-actions.json` 加载，也可在工作台保存。格式为 `schemaVersion: 1` 和 `actions` 数组，每个动作包含 `id`、`label`、相对 `cwd`、超时、可选环境变量和产物路径。平台命令使用 `commands.win32`、`commands.darwin`、`commands.linux`，原有 `command` 仍受支持；平台映射缺少当前平台时拒绝执行。

执行前需审阅并信任确切配置。信任绑定规范化配置、规范工作区路径和目录身份。任何变化都会使其失效，排队期间同样重检。同工作区共用一条队列，保留最多 100 条完成记录和有界日志，支持取消。重启把未完成动作标为中断，不自动启动。Host 按可用磁盘空间预留容量，保留 64 MiB 余量；写入失败会传播，不声称旧 Tauri 存储所有者仍在工作。

文件来源包括手动登记、官方 Session 的交付声明、动作产物声明及动作日志。声明不证明本次运行生成了新内容。打开、定位、另存前均检查短时文件身份与路径租约，拒绝链接、路径穿越和 VCS 元数据。打开操作使用文档/图像扩展名允许列表。另存传输固定副本，限制为 512 MiB，并独占创建新目标。请使用新文件名，现有目标不会被覆盖。复制失败可能留下待检查的不完整目标。

## 保护与任务事实

在**连接与迁移**中启用明确的受保护路径。工作台提供快照列表、恢复预览，并仅按最新预览版本恢复选定路径。原生检查保留 Win32 目录/文件身份、重解析点和硬链接排除、保留策略及恢复回执。任务或工程命令持有准入时不执行恢复。文件变化时报告冲突，不覆盖无关编辑。采集、身份重检或封存结果未知时，阻断后续执行，等待检查与重启。

运行时归属明确的子会话使用相同保护根时，可共用父任务采集，最后一个所有者退出才封存。无关任务操作重叠根会被拒绝，不相交根可并行。工程命令参加同一协调器。快照仅覆盖选定路径，不能约束外部应用。

任务状态根据官方 Session 事实投影，涵盖等待工具、权限、取消和未知结果，不重放工具。通知需主动开启，并从当前游标开始：Main 轮询有界的 turn-end 事实，工作台关闭后仍可通知。该设置仅在本次应用运行有效。构建完成通知在工作台打开期间观测。通知是辅助信息，不是持久执行回执。

## 模型体验与官方升级

`list_project_actions` 向模型提供动作 ID、名称、超时和信任状态。`run_project_action` 接受已信任的 ID，通过官方工具机制返回记录结果及有界输出。模型不能授予信任、选择 Git 的无限制权限或提供任意替代命令。模型执行解析自身会话权限及保护准入，中断或未知结果不构成自动重试许可。

升级官方引擎时需重验 Host 认证路由组合、`agent/pre-step`、`session/event`、`tools/pre-execute`、运行时 Agent 归属、Shell 结果契约、Session query、交付事件及官方编辑器插入坐标。原生 helper 增加规范路径准入解析，必须与对应 Host 一起交付。适配器来源见 [origin.json](origin.json)。草稿桥是窄客户端补丁；工作台和迁入模块保持在 Desktop Host 中，由包内 bundler 明确纳入带类型声明的 JavaScript 适配器。

设置 `DSH_DESKTOP_BUILD_CANDIDATE=m3` 可在 `targets/win-x64/candidates/m3` 构建，不替换正在运行的 M2 或内网包。必须保留完整 `win-unpacked` 目录。可重复验收由 `tests` 下五个脚本、聚焦 Vitest、`smoke-desktop.mjs`、原生 helper 测试及标准完整打包/运行时检查组成。证据与实施报告注明最终验收字节和剩余发行边界。
